# RobotArm
Student project aiming to make a simulator for a set robot-arm (3-4 degrees of freedom)

### Actuellement sur ce projet
Le projet comprend
-  modèles géometriques directs et indirects 
- une vérifiaction de la consistence du modèle(MGI*MCD=Id)
- interface homme-machine.
