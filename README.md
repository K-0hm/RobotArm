# RobotArm
Student project aiming to make a simulator for a set robot-arm (3-4 degrees of freedom)

## Contenu
- Ce dépot contient un simulateur pour un robot 4 ddl (RRPR) ainsi qu'un robot ABB
- gui.py  et Robot.py contiennent l'interface graphique et la dynamique du robot RRPR. gui.py est l'executable.
- InterfaceABB.py et robotABB.py contiennent l'interface graphique et la dynamique du robot ABB. InterfaceABB.py est l'executable.
